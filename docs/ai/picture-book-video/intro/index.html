儿童绘本视频

使用 AI 技术和 n8n 自动化工作流，实现从故事编写到视频生成的完整自动化流程。

📌 课程简介​

本教程将指导你如何使用本地 Docker 部署 n8n、Flux、Kling AI、ElevenLabs 等工具，构建一个完整的自动化儿童绘本视频生成系统。通过 n8n 工作流，实现从故事编写、分镜图生成、视频生成、儿童配音到最终视频合成的全自动化流程。

通过这个教程，你将学会：

  • 🐳 使用 Docker 本地部署 n8n 自动化平台
  • ✍️ 使用 AI 自动生成儿童故事脚本
  • 🎨 使用 Flux 生成绘本分镜图
  • 🎬 使用 Kling AI 生成视频片段
  • 🎙️ 使用 ElevenLabs 生成儿童配音
  • 🔄 配置 n8n 自动化工作流串联所有步骤
  • 🎞️ 自动合成最终视频

🎯 学习目标​

完成本教程后，你将能够：

  1. ✅ 在本地使用 Docker 部署 n8n 自动化平台
  2. ✅ 配置 Flux、Kling AI、ElevenLabs 等 AI 工具
  3. ✅ 使用 AI 自动生成儿童故事内容
  4. ✅ 生成符合故事的分镜图和视频
  5. ✅ 生成高质量的儿童配音
  6. ✅ 构建完整的自动化工作流
  7. ✅ 自动合成和导出最终视频

📚 学习路径​

本教程将按照以下流程进行：

环境准备 → 故事编写 → 分镜图生成 → 视频生成 → 儿童配音 → n8n自动化 → 视频合成 → 优化与发布

第一步：环境准备​

  • 安装 Docker 和 Docker Compose
  • 部署本地 n8n 实例
  • 配置基础环境

第二步：故事编写​

  • 使用 AI 生成儿童故事脚本
  • 故事结构化和分页处理
  • 准备故事素材

第三步：分镜图生成​

  • 配置 Flux 图像生成工具
  • 根据故事内容生成分镜图
  • 优化和调整图像

第四步：视频生成​

  • 配置 Kling AI 视频生成
  • 将分镜图转换为视频片段
  • 视频质量优化

第五步：儿童配音​

  • 配置 ElevenLabs 语音合成
  • 生成儿童角色配音
  • 调整语音参数和情感

第六步：n8n 自动化工作流​

  • 设计完整的工作流流程
  • 连接各个 AI 工具
  • 配置自动化触发和执行

第七步：视频合成​

  • 将视频片段和音频同步
  • 添加转场和效果
  • 生成最终视频

第八步：优化与发布​

  • 视频质量检查
  • 添加字幕和标题
  • 导出和发布

⏱️ 预计学习时间​

  • 环境搭建：2-3 小时 - Docker 和工具部署
  • 工具配置：2-3 小时 - 配置各个 AI 工具
  • 工作流构建：3-4 小时 - 设计和实现自动化流程
  • 测试优化：2-3 小时 - 测试和完善系统

💻 前置知识​

必需：​

  • 基础的 Docker 使用经验
  • 对 AI 工具有基本了解
  • 基本的命令行操作

推荐：​

  • n8n 工作流设计经验
  • 视频编辑基础知识
  • 对自动化流程的理解

🛠️ 所需工具​

  • Docker - 容器化部署
  • n8n - 自动化工作流平台
  • Flux - AI 图像生成
  • Kling AI - AI 视频生成
  • ElevenLabs - AI 语音合成

💡 学习建议​

  1. 按步骤操作 💪
    严格按照教程顺序执行，确保每个工具都正确配置

  2. 测试验证 ✅
    每个步骤完成后都要测试功能是否正常

  3. 保存配置 💾
    妥善保存 API Key、配置文件等重要信息

  4. 逐步构建 🏗️
    先完成单个工具配置，再构建完整工作流

  5. 持续优化 ✨
    根据实际效果调整参数和流程
